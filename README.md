# NextGen Tech Solutions website

Static website (HTML + Tailwind CSS + vanilla JS). No build step, no backend yet.

## Run it
Open the folder in VS Code and use the **Live Server** extension, or run `npx serve .` in this folder. Double-clicking `index.html` also works.

## Change the basics
- **Colours:** the first three lines in `:root` in `assets/css/theme.css`. Light and dark mode both follow.
- **Company name, email, phone, WhatsApp, links:** `assets/js/config.js`.
- **Header / footer:** `components/header.js` and `components/footer.js` (shared by every page).

## Deploy
Upload the folder to Netlify (drag and drop), Vercel, Cloudflare Pages or GitHub Pages. No build command needed.

## Before going live
Replace the placeholders listed in `AGENT.md` section 10, and have a lawyer review `terms.html` and `privacy.html`.

For full conventions (for developers and AI coding agents), read **AGENT.md**.
